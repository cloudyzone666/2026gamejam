# 卡面布局调节与验收

2026-11-24。仅控制上方角色和敌人卡面，下方书本继续使用现有界面。

## 使用工具

1. 打开 `Assets/Scenes/SampleScene.unity`。
2. 菜单打开 `Card Cards/UI/卡面布局调节`。
3. 进入 Play Mode，窗口会调整运行时副本，Game 视图实时预览。
4. 先调整卡面宽度、重叠比例和内外侧缩放，再调整倾角、透视距离及浮动。
5. 满意后点击“保存参数”。退出 Play Mode，再次运行，检查参数已经保留。未保存的运行时尝试会丢弃。

默认配置为 `Assets/Data/Battle/CardFormation.asset`，已经绑定到场景 `Canvas` 上的 `BattleView.cardFormationSettings` 及双方排列组件，无需用户手工接线。

| 参数 | 单位与用途 |
| --- | --- |
| 双方位置、透视中心 | 参考 Canvas 左上角坐标，X 向右、Y 向下；1280×720 的中线为 X=640 |
| 卡面基础宽度 | Canvas 单位；基础根高度 274 包括卡外标签，用缩放调整整体尺寸 |
| 重叠比例 | 值越大，槽位间距越小；0 表示间距等于基础宽度，最终重叠还受缩放和透视影响 |
| 内外侧缩放、大小渐变指数 | 调整靠中央与靠边缘的大小和变化方式 |
| 镜像透视倾角、透视距离 | 倾角为 0–40 度，双方自动镜像；距离为卡根局部投影单位，最小 180，越小近大远小越明显 |
| 浮动幅度、周期、节奏差 | 幅度为卡根局部坐标单位、周期为秒、相位差为弧度 |
| 悬停抬升与缩放 | 默认 0 与 1，即只改变遮挡；抬升为卡根局部单位，会随整体缩放 |
| 暂停浮动 | 冻结当前浮动高度，便于画面对齐 |
| Scene 编号与轮廓 | 显示每侧从左至右编号和实际卡面命中四边形 |

“双方联动”以我方参数为编辑源，每次修改共同参数时同步到敌方；双方位置始终独立。仅勾上开关不会立即覆盖已有差异，取消后可分别调整。工具支持 Ctrl+Z、恢复默认及保存。调整较大卡面尺寸时，配合位置与重叠比例，使卡面留在上方战场。

## 操作规则

- 每侧按屏幕左到右计算显示编号，奇数卡覆盖偶数卡；卡上原有“前排/位次”仍是战斗编号。
- 每侧可固定一张点击置顶卡；悬停临时盖过固定卡，离开后恢复。
- 点击同侧另一张切换固定卡；点击战场空白或 Esc 清除双方固定。Esc 原有取消目标选择行为继续生效。
- 悬停冻结该卡待机浮动，移开后恢复；拖拽结束沿用原整顿换位规则。
- 死亡后存活卡收拢并重新计算显示层级；固定状态随角色身份保留，死亡或重开清除。

## 接线与代码边界

- `Canvas/AllyRow`、`Canvas/EnemyRow`：新增 `CardFormationLayout`，旧 `HorizontalLayoutGroup` 已停用并保留。
- `CharacterCard.prefab`：新增 `CardPresentation`；运行时绑定图形投影组件并生成透明 `CardPresentationHitArea`。卡面内部仍由原 `CardVisual` 处理 180°旋转。
- 书本对象、背包、装备槽及战斗结算数据沿用既有实现；卡外护盾和文字继续保持正向可读。
- `CardFormationAuthoring.Apply` 是定向接线入口，正常使用无需运行；它只接卡面，不重建 Canvas。

## 人工验收

在默认 4v4 中逐张悬停、点击，再悬停其他卡，检查层级恢复及双方固定可并存。随后尝试旋转、翻面、整顿换位、选择目标、击杀和重开。工具中调大抬升、放大和浮动，检查边缘悬停稳定、可见部分能点中，保存后重新运行检查参数保留。书本的布局、装备拖拽和按钮也应保持可用。

自动验证与实际画面复核结果见 `ENV_CHECK.md`；自动输入不能替代人工手感评价。
